FEATHER GHOST - le copier-coller qui tape lettre par lettre

INSTALLATION (une seule fois)
  pip install -r requirements.txt

LANCEMENT
  python feather_ghost.py

UTILISATION
  1. Colle ton texte dans la fenêtre.
  2. Règle la vitesse (et le délai après clic, 1 s par défaut).
  3. Clique sur "Lancer", puis clique une fois dans le document/champ où écrire :
     c'est ce premier clic qui désigne la cible.
     En mode arrière-plan (Windows), tu peux ensuite faire autre chose.
  4. Échap = arrêt d'urgence.

CRÉER UN .EXE (Windows)
  pip install pyinstaller
  pyinstaller --noconsole --onefile --icon feather_ghost.ico --add-data "feather_ghost.ico;." --name FeatherGhost feather_ghost.py

NOTES
  - macOS : autoriser le Terminal/l'app dans Réglages > Confidentialité > Accessibilité.
  - Les applis lancées "en administrateur" ne reçoivent pas la saisie d'une appli normale :
    lance alors Feather Ghost en administrateur aussi.

INSTALLER SUR MAC (macOS)
  Double-clique sur "Installer-macOS.command".
  (Si macOS refuse : clic droit sur le fichier > Ouvrir > Ouvrir.)
  Il installe "Feather Ghost.app" dans ton dossier Applications (celui de ton compte),
  avec l'icône. Au premier lancement, autorise l'appli dans
  Réglages Système > Confidentialité et sécurité > Accessibilité
  et "Surveillance de l'entrée".
  Sur Mac, le mode arrière-plan Windows n'existe pas ; le mode WordCraft (contrôle direct) fonctionne.
  Pour désinstaller : supprime "Feather Ghost.app" et le dossier
  ~/Library/Application Support/FeatherGhost
