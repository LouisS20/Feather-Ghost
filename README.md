# Feather-Ghost
Feather Ghost est un outil ingénieux qui repense le copier-coller traditionnel. Plutôt que de injecter du texte de manière instantanée dans le presse-papier, l'application simule un clavier physique et tape votre texte caractère par caractère, à la manière d'un fantôme invisible qui pianote sur votre clavier.
